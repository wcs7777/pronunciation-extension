# Privacy Policy

This addon does not collect any type of user data, neither their activity in the web or the sites that they visit.
Data is stored only locally in the device that the addon was installed for customization of the addon through the options that the user set and to improve performance of previous words/texts searched.
The source code can be verified here if any doubt remain [https://github.com/wcs7777/pronunciation-extension/tree/chrome](https://github.com/wcs7777/pronunciation-extension/tree/chrome).
